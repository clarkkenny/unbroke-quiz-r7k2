How broke are you?

A quiz that knows more about you than your banking app does. Take the next 2 minutes to discover your status.

Test build. The quiz is a self-contained widget hosted separately from Webflow. You add it with one Code Embed element, plus a hidden Webflow form that receives the signups. It brings its own questions, email pop-up, results page, PDF download, sharing and fonts. Nothing else on the site needs to change.

Feeling broke is temporary. What you learn in this book shouldn't be.

Add it to Webflow

Paste these two lines into one Code Embed element where the quiz should sit. Then add a Form Block to the same page, name it Quiz Signup, give it First Name, Last Name and Email fields, and hide it. The widget fills that form in and submits it, so every signup lands in Webflow form submissions.

<div data-unbroke-quiz></div>
<script src="https://clarkkenny.github.io/unbroke-quiz-r7k2/widget/unbroke-quiz.js" defer></script>

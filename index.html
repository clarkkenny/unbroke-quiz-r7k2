How broke are you?

A quiz that knows more about you than your banking app does. Take the next 2 minutes to discover your status.

Test build. The quiz runs entirely inside Webflow: one Code Embed holds the quiz and all its copy, one script goes in the page settings, and a hidden Webflow form receives the signups. It brings its own questions, email pop-up, results page, PDF download and sharing. Nothing else on the site needs to change. GitHub only hosts this demo.

Feeling broke is temporary. What you learn in this book shouldn't be.

Add it to Webflow

Four steps, all inside Webflow. The two code files are in the webflow folder of the project.

  1. Font. Add Inter Tight in Site settings > Fonts.
  2. Code Embed. Paste 1-code-embed.html where the quiz card should sit. All the quiz copy is inside it.
  3. Page script. Paste 2-before-body.html into the page's Custom code, Before </body> tag.
  4. Signup form. Add a Form Block named Quiz Signup with First Name, Last Name and Email fields, and hide it.
